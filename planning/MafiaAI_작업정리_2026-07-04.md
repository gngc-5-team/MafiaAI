## 2. ★ 밤 "공간 사냥" 기능 — 코드 구현 완료 (⚠️ 라이브 컴파일 미검증)

**컨셉:** 밤이 추상 10초 UI 선택 → **실시간 공간 사냥**으로. 인간 마피아가 어두운 저택에서 피해자에게 직접 접근해 **Space로 살해**. 사망 표시/정산은 기존대로 **새벽에만**. 비마피아는 밤에 **시야 반경이 크게 좁아짐**(암전).

**확정된 결정(사용자):** 살인 키 **Space** · **인간이 마피아일 때만** 공간 사냥(AI 마피아는 기존 추상 유지) · 밤 **15초**.

**수정 파일 5개:**
- `Assets/MafiaAI/Scripts/LLM/GameConfig.cs`
  - `NightSeconds` 10→**15**
  - 신규: `SpatialNightHunt=true`, `KillRadius=1.6`, `MafiaNightVision=6.0`, `CitizenNightVision=2.3`
- `Assets/MafiaAI/Scripts/LLM/HumanActor.cs`
  - `bool SpatialKillMode`, `event OnNeedSpatialKill`
  - `NightAsync`: 인간 마피아+공간모드면 오버레이 대신 `OnNeedSpatialKill` 발생 후 대기(완료는 `SubmitChoice`)
- `Assets/MafiaAI/Scripts/LLM/GameController.cs`
  - Setup에서 인간에게 `SpatialKillMode` 부여
  - `NightKillCandidates()`(생존 비마피아) / `TrySubmitNightKill(id)`(뷰가 호출→`MafiaTarget` 확정)
  - **hunt-or-no-kill**: 인간 마피아 밤엔 자동 랜덤 살해 폴백 제거(시간초과 시 `ForceResolveChoice(null)` + NightPhase 랜덤 폴백 skip) → 못 죽이면 "조용한 밤"
  - 밤 이동 로그 숨김(은밀)
- `Assets/MafiaAI/Scripts/UI/SpriteMansionView.cs`
  - **밤 시야 암전**: 플레이어 추종 방사형(중심 투명→바깥 검정) 스프라이트 런타임 생성(`SetNightMaskHole`, sortingOrder 500). 마피아=넓게/비마피아=좁게. URP 2D 라이트 불요, 런타임 토큰에도 먹힘
  - **Space 살인**: `HandleNightKill` — `KillRadius` 내 최근접 대상 → `TrySubmitNightKill`. 밤당 1회 잠금
  - `KillFeedback` 코루틴: 피해자 붉게 + "제거" 표식 1.2초 후 원복(사망은 새벽에만 드러남)
  - `HandleNightPhase`로 페이즈별 암전 on/off + kill 플래그 리셋. `using MafiaAI.Core`, `using System.Collections` 추가
- `Assets/MafiaAI/Scripts/UI/MafiaUI.cs`
  - `OnNeedSpatialKill` 구독 → 하단 힌트 "[밤] 어둠 속에서 대상에게 접근한 뒤 Space로 살해하라". 경찰/의사는 기존 오버레이 유지

**정적 검증:** 5개 파일 브레이스 균형 OK, 신규 심볼 연결 OK. **단, Unity MCP 세션이 끊겨 라이브 컴파일 확인 불가.**

**테스트 방법:** 하단 "당신의 정체"가 **마피아**여야 사냥 활성. 특정 판 재현은 `GameController.seed` 고정.

**사용자 veto 후보:** "밤에 못 죽이면 조용한 밤"(현재)을 원래대로 "시간초과 시 자동 랜덤 살해"로 되돌릴지 물어봐야 함.

## 3. 설명만 한 것 (코드 변경 없음)

- **벽 충돌 로직 원리**: 물리 충돌 아님. 방/복도 바닥 스프라이트 bounds를 walkable `Rect` 목록으로 등록 → `IsWalkable(next)`가 true일 때만 이동 허용(화이트리스트). `roomline/corridorline` 검은선은 코드가 참조 안 하는 순수 비주얼. NPC는 x/y 분리 슬라이딩, 방 감지는 살짝 줄인 rect(`Shrink`) 사용.

## 4. 미완 / 대기 항목

- **[대기] Unity MCP 연결 끊김**(`no_unity_session`). 서버는 살아있으나 에디터 세션 미응답. → (1) 밤 사냥 코드 라이브 컴파일 확인, (2) 아래 타일맵 작업이 전부 여기 막힘.
- **[대기] YuminScene 타일맵 배치(B안)**: 흰 사각형 방 몇 개를 타일맵으로 대충 깔기. MCP 연결되면 즉시: `Grid`+`Tilemap` 생성(32 PPU) → `tile-1_0` 흰 타일로 방 배치.
  - 새 에셋: `Assets/sprites/tile-1.png`(177×75, 32PPU, Multiple 슬라이스), `tile-1_0.asset`/`tile-1_1.asset`(Tile), `New Tile Palette.prefab`
  - ⚠️ 주의: 현재 `SpriteMansionView`는 `room1~5` 개별 SpriteRenderer 오브젝트를 `GameObject.Find`로 바인딩. 타일맵으로 방을 그리면 이 방식과 달라지므로 연결 방식 재설계 필요(A안=로직 정합 배치는 별도 결정).
- **새 씬/팀 작업 감지**: `Assets/Scenes/YuminScene.unity`, `JongHoonScene.unity` 추가됨(협업자 씬으로 추정). 메인 씬이 SampleScene에서 바뀌었는지 확인 필요.
