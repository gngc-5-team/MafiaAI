# 게임 기획서 — **AI 마피아**

> **6인 마피아 게임을 5명의 Gemma 4 AI와 함께 플레이한다.**
> AI 하나하나가 고유 페르소나 + 비밀 역할을 갖고, **매 턴 프롬프트로 인격이 주입**되어
> 서로를 의심하고, 거짓말하고, 밤에 능력을 쓰고, 투표한다. 당신은 그 틈에 낀 유일한 인간.

작성일: 2026-07-03 · 스택: Ollama `gemma4:latest`(로컬) · 기존 Pokerface_AI 인프라 재사용

---

## 1. 한 줄 컨셉

> **"5명의 AI 사이에서, 사람처럼 거짓말하는 AI 마피아를 텍스트로 색출하라."**

- 정형화된 봇이 아니라 **LLM 특유의 자유로운 대화**로 심리전을 건다.
- 매 게임 페르소나·역할·대화가 달라져 **리플레이성**이 무한.
- 주제 **인공지능**에 정면으로 부합 — "AI가 사람처럼 거짓말하고 설득한다"가 게임의 본질.

---

## 2. 게임 설정 (심플)

6명이 마피아 게임을 한다. 그중 **나 빼고 5명이 전부 AI.** 각 AI는 서로가 사람인 척,
자기 역할을 숨기며 플레이한다. 나는 대화로 마피아를 추리해 낮에 투표로 처형시키고,
마피아는 밤마다 한 명씩 제거한다. **역할·성격·대사가 매판 랜덤**이라 같은 판이 없다.

> 별도의 SF 세계관 없이, **정통 마피아 규칙 그대로** + "상대가 전부 AI"라는 점만 새롭다.

---

## 3. 핵심 재미 (Hook)

1. **살아있는 거짓말** — 마피아 AI는 매 턴 새로 생성되는 변명·역공작으로 빠져나간다.
   같은 상황도 매번 다르게 둘러댄다. "정형 대사 = 지루함"을 LLM이 깬다.
2. **인격의 충돌** — 다혈질/소심/능글/냉정 등 페르소나가 달라서, 역할과 무관하게
   대화 자체가 드라마가 된다. (조용한 시민이 억울하게 몰려 처형당하는 참극)
3. **관전 + 개입의 쾌감** — 5 AI가 알아서 서로 물어뜯는 걸 지켜보다가, 결정적 순간
   내가 던진 한 문장이 판을 뒤집는다. ("그 말, 아까랑 다르잖아")
4. **AI를 심리적으로 압박** — 특정 AI를 집요하게 추궁하면, 마피아의 진술에
   **논리적 균열(모순)**이 생기고, 그걸 들이밀면 여론이 쏠린다.

**유사 게임 대비 차별화 선언:**
> *"기존 마피아 봇은 정해진 대사를 뱉지만, 우리 AI는 매 턴 생성된 인격으로 당신을 속인다."*

| | Among Us | 일반 마피아 앱(룰봇) | **AI 마피아** |
|---|---|---|---|
| NPC 대화 | 없음 | 정형 템플릿 | **LLM 자유 생성** |
| 리플레이성 | 중 | 하 | **상(페르소나×역할 랜덤)** |
| 거짓말의 질 | 사람끼리 | 없음 | **AI가 사람처럼** |

---

## 4. 역할 구성

6인 = 플레이어(인간) 1 + AI 5. 역할은 매판 랜덤 배정.

| 역할 | 인원 | 진영 | 능력(밤) |
|------|------|------|----------|
| **마피아** | 1 | 마피아 | 밤에 한 명을 제거 |
| **경찰** | 1 | 시민 | 밤에 한 명을 조사 → 마피아 여부 확인 |
| **의사** | 1 | 시민 | 밤에 한 명을 보호 → 그날 밤 제거 방어 |
| **시민** | 3 | 시민 | 능력 없음. 대화·추리·투표로 기여 |

- 플레이어도 랜덤 역할. **마피아로 배정되면 = 인간이 AI 5명을 속이는 역모드** (밈각).
- 승리조건 — **시민 진영:** 마피아 처형. **마피아:** 마피아 수 ≥ 시민 수(동수 포함).

## 5. 코어 게임플레이 (하루 사이클)

```
① 밤 (NIGHT)   ─ 능력자 각자 대상 지정 (AI는 프롬프트로 판단, 인간은 UI 선택)
                  · 마피아: 제거 대상 1
                  · 경찰: 조사 대상 1 → 결과 비밀 통지
                  · 의사: 보호 대상 1
                  밤 결과 정산 (보호 성공 시 제거 방어)

② 새벽 (DAWN)  ─ "OOO 이(가) 밤사이 살해되었습니다" 공개 (방어 성공 시 "조용한 밤이었다")

③ 낮 토론      ─ 생존자 전원 순서대로 발언 (라운드 1~2회)
                  · AI 발언 = Gemma 호출(페르소나 + 맥락 프롬프트)
                  · 인간 = 자유 텍스트 입력 + 특정 인물 지목 질문 가능
                  · 의심 여론이 대화 로그로 축적

④ 투표 (VOTE)  ─ 전원 1표씩 지목 → 최다 득표자 처형 → 역할 공개

⑤ 승패 판정    ─ 아니면 ①로 반복
```

## 6. ★ AI 아키텍처 (이 게임의 심장) ★

핵심 요구사항: **AI 하나마다 매 턴 페르소나 프롬프트를 주입해 Gemma가 인격을 연기.**
5명을 **하나의 gemma4:latest 모델로 순차 호출**해 굴린다(모델 5개 아님, 프롬프트 5종).

### 6.1 에이전트 1명의 프롬프트 조립 (매 턴 재조립)

```
[SYSTEM] ── 고정 인격 (게임 내내 유지)
  · 페르소나: "너는 '카이'. 다혈질이고 직설적이며 의심이 많다.
              말이 짧고 공격적이다. 이모지 금지, 한국어, 2문장 이내."
  · 역할 & 승리조건 (역할별로 다름 ↓)
  · 규칙: "너는 AI지만 절대 정체를 들키지 마라. 사람처럼 행동하라."

[CONTEXT] ── 공개 정보 (매 턴 갱신, 요약본)
  · 현재 Day/페이즈, 생존자 목록
  · 지금까지의 공개 대화 로그 (최근 위주로 요약)
  · 사망/처형 기록

[PRIVATE] ── 이 에이전트만 아는 비밀 (역할별)
  · 마피아: "너의 정체는 마피아다. 낮엔 무고한 척, 의심을 남에게 돌려라."
  · 경찰:   "너의 조사 결과: Day1 라온=시민(무고), Day2 미로=마피아!"
  · 의사:   "네가 보호한 기록: ..."
  · 시민:   (비밀 없음)

[TASK] ── 이번 턴 지시 (페이즈별로 다름)
  · 토론: "이번 턴 한 마디 발언하라. 근거를 들어 누군가를 의심하거나 변호하라."
  · 투표: "누구에게 투표할지 정하라. 아래 JSON으로만 답하라."
  · 밤:   "능력 대상을 정하라. 아래 JSON으로만 답하라."
```

### 6.2 발언(자유 대화) vs 행동(구조화 출력) 분리

- **토론 발언** = 자연어 그대로 (재미의 원천). Ollama 일반 호출, `temperature 0.9`.
- **투표 · 밤 능력** = **구조화 출력**으로 파싱 안정성 확보:
  Ollama `format: json` + 스키마 강제.
  ```json
  { "target": "라온", "reason": "발언이 계속 바뀜" }
  ```
  파싱 실패 시 폴백: 이름 문자열 매칭 → 그래도 없으면 랜덤/기권.

### 6.3 마피아 AI의 기만 설계

- SYSTEM에 **"너는 마피아지만 심문받으면 무고한 시민처럼 행동. 다른 사람에게 의심을
  유도하고, 경찰·의사인 척 사칭(클레임)해도 된다"** 명시 → 자발적 블러핑.
- 밤 제거 대상 선택 시 CONTEXT에 "너를 강하게 의심하는 사람 우선 제거 고려" 힌트.

### 6.4 "의심도" — 별도 수치 없이 대화에서 창발

- 명시적 게이지 대신, **누가 누구를 지목/변호했는지**를 로그로 카운트해
  UI에 인물별 `의심 ●●●○○` 표시(가벼운 집계). LLM 판단은 대화 맥락에서 자연 발생.
- (선택 확장) 매 Day 종료 시 별도 요약 호출로 인물별 수상함 점수 산출.

### 6.5 성능 · 비용 (반드시 설계에 반영)

| 이슈 | 대책 |
|------|------|
| 5 AI × 토론 = 지연(각 호출 2~4초) | **순차 호출 + 타자기 스트리밍** → "지켜보는 맛"으로 전환 |
| 컨텍스트 토큰 증가 | 대화 로그 **요약 압축**(Day별 3줄), 최근 N발언만 원문 유지 |
| 반응 더 빨라야 | 시민 3명은 `gemma3:1b`(경량), 핵심 역할만 `4b` 혼용 가능 |
| JSON 깨짐 | `format:json` + 이름 매칭 폴백 + 재시도 1회 |
| 첫 호출 로딩 지연 | 게임 시작 전 `ollama run gemma4:latest` 워밍업 |

> 이미 깔린 `gemma4:latest` + 기존 `dealer_llm.py`의 Ollama 호출 코드를 그대로 확장하면 됨.

## 7. 핵심 기능 & 기믹

- **심문 UI** — 인물 아바타 6개 + 실시간 대화 스트림. 내 발언은 채팅창처럼 입력.
- **지목 질문** — 특정 인물을 콕 찍어 질문하면 그 AI가 우선 반응(프롬프트에 "너에게 질문이 들어왔다").
- **모순 포착(연출)** — 같은 인물의 앞뒤 발언이 충돌하면 UI가 하이라이트 → "추궁" 버튼.
- **밤 연출** — 화면 암전 + 사망자 아바타 흑백 처리.
- **정체 공개** — 처형/사망 시 역할 카드 뒤집기 + 진영 효과음.
- (스트레치) **웹캠 연동** — 포커페이스 자산 재사용: 투표 순간 인간의 불안도를 AI가 읽고
  "손이 떨리는데요?"라고 역으로 압박.

## 8. 구현 범위 (MVP)

**🔴 반드시 (2박3일 기준 첫날밤~둘째날)**
- 6인 역할 배정 + 밤/새벽/토론/투표 상태머신 (규칙 로직, C# 또는 Python)
- Gemma 에이전트 1종 파이프라인(프롬프트 조립 → 발언 → 파싱)을 5명으로 복제
- 텍스트 토론 1라운드 + 투표 + 밤 능력(마피아/경찰/의사) 최소 동작
- 승패 판정, 한 판 끝까지 플레이 가능

**🟡 여유되면**
- 지목 질문, 모순 하이라이트, 타자기 스트리밍, 의심도 집계 UI
- 페르소나 5~6종 다양화, 마피아 사칭(클레임) 로직

**⚪ 과감히 컷**
- 마피아 2명 담합, 웹캠 연동, 음성 TTS, 세이브/리플레이, 온라인 멀티

## 9. 아트 & 사운드 톤

- **비주얼:** 어두운 배경 + 인물 아바타(픽셀 초상 또는 심플 일러). 감정 상태에 따라 표정 변화.
  깔끔한 채팅/취조 인터페이스. (원하면 사이버틱하게, 원하면 보드게임 감성으로 조정 가능)
- **컨셉아트 방향(무드보드 키워드):** `마피아 취조실`, `채팅 UI`, `Among Us 캐릭터`,
  `누아르 심문`, `심플 아바타 일러`.
- **사운드:** 잔잔한 긴장 앰비언트 + 타이핑 SFX + 밤 전환 하트비트 + 처형 시 임팩트음.

> ⓘ 컨셉아트는 이미지 생성 툴(위 키워드 프롬프트)로 4~6장 확보 → 발표덱 삽입.
