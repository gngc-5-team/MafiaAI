## 2. 코드 구조 (`Assets/MafiaAI/Scripts/`)

```
Core/   순수 C# 규칙 엔진 (UnityEngine 비의존, 테스트 가능)
  GameEnums.cs    역할/진영/페이즈/승자 열거형 + 한글 변환
  Player.cs       플레이어 모델(역할·페르소나·조사기록·보호기록)
  Persona.cs      AI 성격 프리셋 8종 + 랜덤 뽑기
  GameState.cs    게임 상태 컨테이너(생존자·로그·밤액션·투표)
  GameRules.cs    역할배정·밤정산·투표집계·승패판정

LLM/    AI 파이프라인
  OllamaClient.cs   ★ LLM 연결 유일 지점. GenerateAsync(model,prompt,system,temp,jsonFormat,ct)→string
  PromptBuilder.cs  SYSTEM/CONTEXT/PRIVATE/TASK 프롬프트 조립 (발언·질문·반박·투표·밤·방문답)
  Actors.cs         AIActor(=Gemma 좌석). GenerateAsync 호출 8곳
  HumanActor.cs     인간 좌석. UI가 Submit*로 응답 주입(TaskCompletionSource)
  ActionParser.cs   JSON 파싱 + 이름매칭 + 랜덤 폴백
  GameConfig.cs     튜닝값(시간·온도·모델명 등)
  GameController.cs  밤/낮/투표 상태머신 + 저택 방 이동 로직 구동

UI/
  MafiaUI.cs           다크 누아르 취조 UI(대화 스트림·타이머·정체/위치 바·입력·오버레이)
  SpriteMansionView.cs 씬 배치 스프라이트(room1~5, corridor1~4)에 이동·방감지·카메라 바인딩
```

### ★ 핵심: LLM은 파일 1개로 격리돼 있음
게임 전체가 AI에 말 거는 통로는 **`OllamaClient.GenerateAsync` 단 하나**. 호출처는 `Actors.cs`(8곳)+`GameController` 워밍업(1곳)뿐.
→ 백엔드(Ollama)를 다른 걸로 바꿔도 **이 파일 내부만** 재구현하면 됨. 게임 로직·프롬프트·UI는 무손상.

## 3. 이번 세션에 한 작업 (완료)

1. **Phase 0~3 전체 구현·검증** — 스캐폴딩→순수C# 상태머신→AI 파이프라인→다크누아르 UI + 인간 개입(발언·투표·밤). 한 판 끝까지 플레이 확인.
2. **심사 피드백 반영**
   - 저정보 루프("저도 시민입니다") 제거 — 토론 프롬프트에 하드 제약(이름 지목+이전발언 인용+무의미선언/앵무새 금지+2문장).
   - AI 1인칭 정체성 — 지목당하면 자기를 '그/그녀'로 안 부르고 '나/저'로 반박.
   - 역할 심리전 — 경찰 공개 타이밍/가짜경찰 반박, 의사 정체공개 딜레마, 마피아 사칭·맞불.
   - 지목 추궁(Press) — 특정 AI 콕 찍으면 즉시 반박 턴.
   - 플레이어 발언이 묻히지 않게 반드시 관련 AI가 반응.
3. **저택 공간 시스템(코덱스 협업)** — 방/복도 스프라이트 기반 이동, 같은 방만 대화 청취, AI끼리 1:1 방 문답. (`SpriteMansionView`, `GameController` 방 로직)
4. **시간제 진행 + 타이머** — 낮 60초 / 밤 10초. 상단 중앙에 낮/밤 카운트다운 타이머(`GameController.PhaseEndsAt` + `MafiaUI.UpdateTimer`). 5초 이하 빨강.
5. **버그 수정** — 이동해도 "현재 위치" 표시가 안 바뀌던 문제. `RefreshMap` 조기반환 경로에서 `RefreshRolePanel()` 호출하도록 수정. (검증: 방2→방3 이동 시 즉시 동기화 확인)
6. **배포 파일 생성** — `README.md`, `setup.sh`(mac/linux), `setup.ps1`(win): Ollama 설치+`gemma4:latest` pull 자동화. `.gitignore`에 Captures/·Screenshots/·`*.gguf`·.DS_Store 추가.
7. **기획서 v2 docx** — `planning/AI마피아_기획서_v2.docx`.

## 5. 대회 제출(빌드) 방향 — 미착수, 결정만 됨

문제: 제출 빌드에서 심사자가 Ollama 설치하는 건 이상함 → **로컬 AI를 게임에 내장**해야 함.

- **불변의 사실:** 모델 가중치(현재 `gemma4:latest` 기준 약 9.6GB)는 어떤 방법이든 빌드에 포함됨. 오프라인 로컬 추론이라 불가피. 로컬 모델 캐시 포함 시 약 **9.6GB+** 필요.
- **결정된 방향:** **LLMUnity**(llama.cpp 래핑 Unity 패키지)로 in-process 추론. Ollama 불필요, 심사자는 빌드만 실행.
- **모델:** `gemma4:latest` 유지하기로 함(품질 우선). ※ 제출처 업로드 용량 한도 확인 필요 — 용량이 안 되면 그때 `gemma3:1b`(약 815MB)로 전환.
- **작업량:** `OllamaClient.cs` 내부만 LLMUnity로 재구현 + `GameController` 로딩 조정 + LLMUnity 패키지 추가 + GGUF를 `StreamingAssets`에 배치. **게임 로직/프롬프트/UI 변경 없음.** 위험도 낮음.
- **추천 타이밍:** 게임플레이·연출을 지금 Ollama로 마저 다듬고, **제출 임박 시 백엔드만 스왑**(파일 1개라 마지막에 붙여도 안전).
