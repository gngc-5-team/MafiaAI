### 2.3 씬에 수동 배치된 맵 오브젝트 (HANDOFF 기준)
- 방: `room1`~`room5` · 복도: `corridor1`~`corridor4`
- 벽(자식): `roomline`, `roomline (1)…` / `corridorline …`
- 규칙: 흰/파란 바닥 = 이동 가능, 검은 line = 벽(통과 불가). 논리 방 이름은 코드상 `방1~방5`.

## 3. 게임 구조 분석 (현재 구현 = 아트가 붙을 자리)

### 3.1 한 판 흐름
`밤(10초)` → `새벽(사망 공개·역할 카드)` → `낮 토론(60초, WASD 저택 이동·같은 방 대화)` → `투표(처형·역할 공개)` → 승패 판정 → 반복.

### 3.2 등장 캐릭터 & 역할
- **6인** = 인간 1 + AI 5. 매판 랜덤 좌석·역할.
- **페르소나 8종**(랜덤 5종 선발): 카이(다혈질·직설), 린(소심·신중), 제로(냉정·분석), 미로(능글·너스레), 라온(정의감·리더), 하루(감정적·눈물), 노아(음모론·과몰입), 세이(무심·짧은말).
- **역할 4종**: 마피아1 / 경찰1 / 의사1 / 시민3.

### 3.3 현재 비주얼 상태 (⚠️ 전부 코드로 그린 프리미티브 — 실제 아트 0개)
스크린샷·코드(`SpriteMansionView.cs`, `MafiaUI.cs`) 분석 결과:

| 요소 | 현재 구현 | 한계 |
|---|---|---|
| 캐릭터 토큰 | 1×1 흰 픽셀을 틴트한 **Among Us풍 박스**(Body/Backpack/Visor/다리). 인간=보라(`8A4DFF`), AI=베이지(`D9B56B`) | 표정·개성·역할감 없음. 8 페르소나가 전부 동일 형태 |
| 저택 맵 | 씬의 **단색 사각형** 방/복도 + 검은 테두리 벽 | 저택 분위기·방별 정체성·가구 없음 |
| UI | 100% 코드 생성 다크 누아르(상단 아바타 바·대화 스트림·타이머·투표/밤 오버레이) | 패널·버튼·아이콘 전부 단색. 브랜딩·연출 자산 없음 |
| 연출 | 없음 | 밤 암전·사망 흑백·처형 임팩트·모순 하이라이트 미구현 |
| 사운드 | 없음 | 앰비언트·SFX 전무 |

> **결론:** 게임 로직·AI·상태머신은 완성. **비주얼은 전부 플레이스홀더**다. 아래 아트 리소스가 "코드가 이미 참조하는 자리"에 그대로 꽂힌다.

## 6. 제작 방식 제안 (20년차 관점)

- **AI 이미지 생성으로 1차 확보**: 초상 8종·컨셉아트·키비주얼은 이미지 생성 툴이 톤 맞추기 좋음(기획서 §9 명시). 타일·아이콘은 **일관 팔레트**를 프롬프트에 고정.
- **레이어 분리 원칙**: 캐릭터는 Body/Visor/명찰 분리 PNG로 → 코드의 색 틴트·표정 교체 그대로 활용(리소스 수 절감).
- **타일러블 우선**: 방/복도 바닥·벽은 타일러블로 만들어 씬 수동 배치(유저 선호)에 대응.
- **씬 배치 규약 유지**: 새 스프라이트도 반드시 `room1~5`/`corridor1~4`·`roomline`/`corridorline` 네이밍을 지켜야 `SpriteMansionView` 바인딩이 동작.
- **투입 지점**: 캐릭터/UI = 코드 교체(`SpriteMansionView`·`MafiaUI`), 맵 = 씬 수동 배치. 게임 로직·프롬프트는 무손상.
